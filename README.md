# Laravel React Shop

Fullstack e-commerce application built with **Laravel** and **React**. A modern, responsive application featuring user authentication, product management, shopping cart, and order processing.

## ✨ Features

- ✅ User Authentication (Login/Register) with validation
- ✅ Product Management (CRUD operations)
- ✅ Shopping Cart functionality
- ✅ Order System
- ✅ Responsive Design (Mobile, Tablet, Desktop)
- ✅ Professional UI with Tailwind CSS
- ✅ Form validation (Frontend & Backend)
- ✅ Error handling

## 🛠️ Tech Stack

### Backend
- **Framework**: Laravel 11
- **Environment**: Sail (Docker)
- **Database**: MySQL
- **PHP**: 8.3+

### Frontend
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Icons**: Lucide React

## 🚀 Getting Started

### Backend Setup
```bash
cd laravel-react-shop
sail up -d
sail artisan migrate
```

### Frontend Setup
```bash
cd react-tienda
npm install
npm run dev
```

Backend: http://localhost:8000
Frontend: http://localhost:5173
